# Аудиопаки AutoInformant Pro

Первая публичная коллекция готовых аудиотек для карт openOMSI.

| Пак | Карта (alias) | Аудиофайлов | Размер | Файл |
| --- | --- | :---: | :---: | --- |
| Информатор Твери | `Tver_2026` | 173 | 13,4 МБ | `tver-2026.aipack` |
| Информатор Чугуева | `Chuguev` | 73 | 2,2 МБ | `chuguev.aipack` |
| Информатор Чистогорской области | `Chistogorskaya oblast` | 497 | 23,1 МБ | `chistogorskaya-oblast.aipack` |

## Установка

1. Скачайте нужный `.aipack` из списка файлов ниже.
2. В AutoInformant Pro откройте **Аудиопаки → Импортировать .aipack**.
3. Выберите файл — пак установится и появится в списке.
4. Загрузите карту и duty в openOMSI. Если для карты несколько паков,
   выберите основной кнопкой **Сделать основным для текущей карты**.

Для Твери доступна категория **«Троллейбусы»** — назначьте её на модель транспорта
кнопкой **Назначить текущий транспорт категории**.

## Совместимость

- AutoInformant Pro 1.10+ (рекомендуется 2.0.2)
- Формат `.aipack`, schema v1
- Windows 10/11

Паки не изменялись с версии 2.0.0 приложения.
