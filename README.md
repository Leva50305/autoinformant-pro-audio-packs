## Установка

1. Скачайте нужный `.aipack` из таблицы ниже.
2. В AutoInformant Pro откройте **Аудиопаки → Импортировать .aipack**.
3. Выберите файл — пак установится в `packs/installed` и появится в списке.
4. Загрузите карту и duty в openOMSI. Если для карты установлено несколько паков,
   выберите основной кнопкой **Сделать основным для текущей карты**.
5. Для Твери при необходимости назначьте категорию **«Троллейбусы»** на модель транспорта:
   пак → **Назначить текущий транспорт категории** (после подключения транспорта в игре).

> Пак можно просто перетащить в папку `packs/exports` рядом с приложением — кнопка
> **Импортировать подготовленные** установит все найденные паки сразу.

### Информатор Твери

Аудиопак для карты **Тверь 2026** с основной библиотекой остановок и отдельной
категорией **«Троллейбусы»**, которая полностью заменяет основной банк для назначенных
моделей транспорта.

- 173 аудиофайла, включая анонсы и звуки категории.
- Категория «Троллейбусы»: 35 файлов, назначения `ZiU-682 | V` и `ZiU | 682G g00`.
- 4 ручных назначения остановок, режим анонсов — по времени, интервал 2 минуты.

### Информатор Чугуева

Компактный пак для карты **Чугуев** с библиотекой остановок и папками маршрутов.

- 73 аудиофайла, 11 папок маршрутов.
- 2 ручных назначения: «Вокзал» и «Автовокзал Чугуев».

### Информатор Чистогорской области

Большой пак для карты **Чистогорская область**: основная библиотека остановок
и папки маршрутов в исходной структуре.

- 497 аудиофайлов, 170 папок маршрутов.
- 3 ручных назначения остановок.

## Что внутри `.aipack`

`.aipack` — обычный ZIP-архив с манифестом и аудиоресурсами:

```
manifest.json          описание пака, профили карт и категорий
pack_icon.png          иконка пака
assets/maps/...        аудиобиблиотека основной карты
assets/categories/...  аудиобиблиотеки категорий транспорта
```

Манифест хранит название, автора, описание, alias карты, настройки профиля,
ручные назначения остановок, игнорируемые остановки и расписания анонсов.
Подробное описание полей — в [`docs/PACK_FORMAT.md`](docs/PACK_FORMAT.md).

| AutoInformant Pro | 1.10+ (рекомендуется 2.0.2) |
| Схема пака | `.aipack` schema v1 |
| openOMSI | карта с указанным alias |
| ОС | Windows 10/11 |

Паки не изменялись с версии 2.0.0. Обновление приложения не требует переустановки паков.
